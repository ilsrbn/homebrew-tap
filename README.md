# Serbin Homebrew tap

```sh
brew install --cask ilsrbn/tap/serbin-sessions
```

Homebrew may ask you to run `brew trust ilsrbn/tap` once.

| Cask | Description | Source |
| --- | --- | --- |
| `serbin-sessions` | Notch panel for Claude Code sessions | [ilsrbn/serbin-sessions](https://github.com/ilsrbn/serbin-sessions) |
